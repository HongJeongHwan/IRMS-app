# IRMS 당첨 확인 앱 (Android)

IRMS 현장점검에서 쓰는 Android 앱의 **설치 파일(APK)을 내려받는 곳**입니다.
이 저장소에는 설치 파일과 설치 안내만 있고, 앱의 소스 코드는 없습니다.

> 이 앱은 **IRMS 사용 권한을 받은 현장점검 담당자**를 위한 것입니다.
> 앱 안의 판매점·당첨 자료는 암호화되어 있어, IRMS에서 열쇠를 받지 않으면 열리지 않습니다.

## 설치하기 (처음 한 번)

1. Android 휴대폰에서 이 저장소의 **Releases** › 맨 위(Latest) 릴리스를 엽니다.
2. `irms-app-<버전>-<코드>.apk` 파일을 눌러 내려받습니다. 와이파이·LTE 어디서나 받을 수 있고 깃허브 로그인은 필요 없습니다.
3. 내려받은 파일을 엽니다. 「출처를 알 수 없는 앱」을 허용하라는 안내가 나오면 **이 출처 허용**을 켜고 돌아와 **[설치]**를 누릅니다.
4. 앱을 처음 열면 당첨 확인 화면에 「처음 한 번 IRMS 화면의 자료 열쇠 QR을 [열쇠 QR 찍기]로 찍어 주세요」가 보입니다.
   - 사무실 PC에서 IRMS에 로그인 › **모바일 앱 › 앱 설치** › **[열쇠 QR 보이기]** 를 누르면 QR과 PIN 6자리가 2분 동안 보입니다.
   - 휴대폰 앱의 당첨 확인 › **[열쇠 QR 찍기]** 로 그 QR을 찍고 PIN을 넣습니다. **통신이 필요 없습니다**(휴대폰이 IRMS에 닿지 않아도 됩니다).
   - **로그인한 사람의 이름으로 앱이 연결됩니다(90일).** 앱 맨 위에 이름·소속과 「~날짜까지」가 보입니다.
   - 끝나기 14일 전부터 「○일 남음」 안내가 보이고, **90일이 지나면 당첨 확인이 막힙니다** — 사무실에서 IRMS에 로그인한 뒤 열쇠 QR을 다시 찍으면 다시 쓸 수 있습니다(저장된 기록 보내기는 계속 됩니다).

## 새 당첨 자료

- 당첨 확인 › **[자료 새로 받기]** 를 누르면 이 저장소의 `wins-data` 릴리스에서 암호화된 최신 자료를 받아, 서명·SHA-256을 확인하고 열쇠로 풀어 넣습니다. 어느 망에서나 됩니다.

## 업데이트

- 앱이 하루 한 번 이 저장소의 최신 릴리스를 확인합니다. 새 버전이 있으면 화면 위에 「새 버전」 띠가 뜹니다.
- **[업데이트]** 를 누르면 앱이 파일을 받아 아래 두 가지를 확인한 뒤 설치 화면을 엽니다.
  - 파일 SHA-256 이 릴리스의 `latest.json` 값과 같은지
  - 파일의 서명 인증서가 지금 설치된 앱과 같은지 (다르면 설치하지 않습니다)
- 마지막 **[설치]** 는 사용자가 누릅니다. 쓰던 자료와 열쇠는 그대로 남습니다.

## 파일 확인 (선택)

각 릴리스 설명에 `APK SHA-256` 과 `서명 인증서 SHA-256` 이 적혀 있습니다. PC에서 받은 파일을 확인하려면:

```powershell
Get-FileHash .\irms-app-<버전>-<코드>.apk -Algorithm SHA256
```
